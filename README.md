## About

This repository is a central archive of larger projects built across programming, systems, machine learning, NLP, and game-development practice.

## Highlighted Projects

- `Project_C_Compiler_in_Python/`: compiler project with GUI experiments and phase documents.
- `Python_SuperMario/`: Python game project.
- `Banglore_Home_Prices/`: ML project with model, server, client, and nginx files.
- `Grammer_Checker_For_NLP/`: grammar checker training work.
- `ASM_to_MachineCode_in_Python/`: assembler tables and generated outputs.


## Getting Started

Clone the repository:

```bash
git clone https://github.com/CoderFatherBB/Projects.git
cd Projects
```

Open the folder or notebook you want to explore. Most directories are self-contained, so start from the local `README.md`, source file, notebook, or project folder for that topic.
